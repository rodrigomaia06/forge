# Live Workout

- The bottom navigation dock may compact while the Live Workout content is scrolled, but must remain visible and restore its full size when touched or when navigating to another tab. Primary tab changes use a short cross-fade plus one persistent selection indicator moving to the active item; they never use a push or lateral slide. Retapping the active tab preserves its current navigation and scroll position. Its state changes should be immediate and smooth, without an additional compact-to-expanded entrance transition. It remains visually separated from the bottom system indicator with a light lower fade. Starting a workout smoothly expands the dock to its five-item width; it contracts again when the workout ends. An active workout replaces the dock's generic play glyph with the workout type's semantic icon, without applying the type colour to dock chrome. While a visible rest timer is running, that dock icon carries its compact `m:ss` countdown.
- The Live Workout list must reserve enough bottom space for the persistent dock so the dashed-outline `Add exercise` action remains reachable after adding many exercises.
- Elapsed and rest timers derive from timestamps and refresh together once per second; active-workout persistence is debounced during ordinary edits, while finishing or cancelling remains immediate.
- Tapping Elapsed opens a compact Workout duration sheet with Forge-owned, platform-neutral start-date and start-time pickers, an Automatic Time Tracking switch, and Reset Start Time. Picker choices remain drafts until Done; Back, Close, and dismissal leave the start timestamp unchanged. Automatic tracking is on by default for new and legacy workouts; turning it off freezes the current elapsed value, and turning it back on resumes from that value. Reset Start Time is a destructive confirmed action that resets the live duration to zero.
- Canceling a live workout always requires a destructive discard confirmation; keeping the workout open does not alter its state.
- The active Rest timer keeps its countdown and adjustments in a compact shared sheet: a large timer, linear progress rail, two equal quick actions, then a destructive Stop timer control. Before expiry the actions are `−10s` and `+10s`; once overdue they become recovery actions (`+30s`, `+1 min`) and the elapsed value turns destructive red. A timestamp-derived owner persists the active end time locally, drives the sheet and dock, schedules one local end-of-rest notification when Rest timer is enabled, uses the user’s sound preference for that notification, and gives foreground completion the configured success haptic. On an iOS development or production build, the generated local ActivityKit target renders that same date interval on the Lock Screen and Dynamic Island, switches its stale state to red overdue, and opens the Rest timer through `forge://rest-timer/open`; it is not available in Expo Go or an unre-built binary, where Forge silently uses the normal timer and notification fallback. Android continues to use its native notification/channel fallback. When `Keep rest timer running` is enabled, the timer continues after zero as an overdue `+m:ss` value until stopped or adjusted.
- Sets and exercise cards reveal compact contextual delete actions with a left swipe; the action remains hidden in the resting state. When open, the destructive surface appears behind the card's retained trailing curve.
- The Add exercises picker dismisses its keyboard when its list is touched or dragged, without preventing the requested list action or dismissing the picker. A downward pull on the shared top drag tab, the X, or the modal backdrop closes it; list content never participates in dismissal dragging.
- Exercises added to a live workout or routine start with three empty sets.
- Live Workout exercise cards retain the saved canonical exercise name and, when the immutable snapshot has it, show concise `Variation · Primary equipment` metadata below it. Metadata never repeats a variation already expressed by the name; legacy snapshots remain name-only. The Add Exercises picker groups its child hierarchy by primary equipment while full equipment remains available to search and filters, and marks assisted-bodyweight choices as assisted rather than presenting them as ordinary machine variants.
- Edit workout is a single local draft for name, workout type, training comment, and custom attributes. Its pencil action remains in the left header action group, immediately after Cancel. Its sheets size to their content with a safe maximum for long lists; single-line text fields use the shared 52 pt form height with vertically centred text, and selection rows use the shared 56 pt row height. Its type picker replaces the sheet content with an explicit Back path, while the sheet X discards the full draft; Back and X use matching muted circular surfaces. Workout types appear as one divided grouped card, use only the height they need, and mark the selected type with Forge's restrained success-surface tint. The training-comment field stays at the 52 pt single-line height until text wraps, then changes once to a 104 pt two-line, internally scrollable field. Attributes retain an optional Forge icon; the labelled picker prioritises common workout context such as mood, focus, energy, recovery, location, conditions, hydration, nutrition, music, and goals, alongside generic choices. Routine-defined attribute names become blank, directly editable live-workout values so a routine provides the template without pre-filling a session's answer. The Live Workout list shows `Attributes` only when attributes exist and `Exercises` only when exercise cards exist. Multiple live attributes are joined as divided rows in one compact grouped card; the editor uses the same grouped treatment and appends its `Add attribute` row to that card, matching the joined Add set pattern. Attribute rows preserve their icon and use a directly editable value. Existing editor rows expose the same left-swipe delete affordance as workout sets, and their focused editor replaces the X with a header trash action.
- If a focused weight or reps field would sit too close to the number keyboard, Live Workout and the Routine Editor temporarily scroll it into the comfortable middle of the visible area. They use native keyboard insets where available and their prior scroll position returns when the keyboard is dismissed.
- Exercise options use Forge action-list and decision patterns, not a tracking-mode override: the catalogue-owned tracking type is never changed from this menu. Their note editor replaces the action list in-place, with Back and an X rather than a separate Done action; notes grow with their content. A saved exercise note appears only as a chat indicator directly after its canonical name, without changing card height or exposing note text. Options also provide completed-session reference, catalogue information, and—when the movement has an absolute-weight field—an editable warm-up ramp that inserts tagged Warm Up sets before working sets. The ramp pre-fills from the latest completed working set when one exists, while remaining editable. Removing an exercise from this menu requires a Forge destructive confirmation; swipe-to-delete remains the fast contextual delete affordance.
- Set-number chips open a Forge bottom sheet with a centred set number, an optional single set kind, a grouped Session note & effort card, and a closely paired grouped Next session target card. Set kind opens an in-place choice view with Back and no duplicate body heading; choosing the current type clears it, while Back preserves every other edit. A selected kind exposes distinct 44 pt Change and destructive-tinted Clear Forge actions. The comment input starts at 80 pt and has no visible character limit. RPE is a horizontally scrollable 44 pt single-choice row from 10 to 6, including halves; its selected value is centred without shrinking targets. Each applicable Next session target is a 56 pt row that focuses its matching input; targets are advisory and never alter the recorded set. History uses the same grouping as static content without change controls. A target is marked by a compact white top-left dot and recorded RPE by its bottom-left value; set comments never add a content row or a visible character limit, using a compact solid, theme-inverted dot at the lower-right edge. Exercise notes similarly use an end-of-name indicator without changing card height. Exercise note editing starts at 156 pt and grows for longer text. Previous sessions and Exercise info replace Exercise options internally, preserving a Forge Back action and the X that closes the whole flow.
- Live Workout and History workout detail reserve symmetric header space so titles remain centered. Back and Cancel are icon-only actions with accessible names; Finish and More retain visible labels.
- An exercise tracking type determines set fields: weight/reps, bodyweight reps, added or assisted weight plus reps, reps-only, duration, duration plus weight, distance plus duration, or weight plus distance. Completed workout history uses its immutable exercise/set snapshot.
- Add Exercises uses a local search and staged Workout type, Equipment, and Category filters. Filters replace the Add Exercises content in its existing sheet rather than opening a second popover; the shared top-right X returns to Add Exercises and discards draft changes. Apply commits the draft, while its pill-shaped Clear control resets the draft without changing visible results until Apply. The Apply control uses the exact floating confirmation treatment and success tint as Add Exercises—fade/vignette, docked position, sizing, press feedback, and sheet motion—but is enabled only when the draft has a selection. A selected type narrows the downstream Equipment and Category choices to compatible catalogue values; stale dependent draft choices are removed. Applied state is communicated by the selected Filters trigger and its active-count badge, preserves existing exercise selections, and uses any-match within a facet and all-match across facets.

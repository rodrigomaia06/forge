# Live Workout

- The bottom navigation dock may compact while the Live Workout content is scrolled, but must remain visible and restore its full size when touched or when navigating to another tab. Primary tab changes use a short cross-fade plus one persistent selection indicator moving to the active item; they never use a push or lateral slide. Retapping the active tab preserves its current navigation and scroll position. Its state changes should be immediate and smooth, without an additional compact-to-expanded entrance transition. It remains visually separated from the bottom system indicator with a light lower fade. Starting a workout smoothly expands the dock to its five-item width; it contracts again when the workout ends. An active workout replaces the dock's generic play glyph with the workout type's semantic icon, without applying the type colour to dock chrome.
- The Live Workout list must reserve enough bottom space for the persistent dock so the dashed-outline `Add exercise` action remains reachable after adding many exercises.
- Elapsed and rest timers derive from timestamps and refresh together once per second; active-workout persistence is debounced during ordinary edits, while finishing or cancelling remains immediate.
- Sets and exercise cards reveal compact contextual delete actions with a left swipe; the action remains hidden in the resting state. When open, the destructive surface appears behind the card's retained trailing curve.
- The Add exercises picker dismisses its keyboard when its list is touched or dragged, without preventing the requested list action or dismissing the picker. A downward pull on the shared top drag tab, the X, or the modal backdrop closes it; list content never participates in dismissal dragging.
- Exercises added to a live workout or routine start with three empty sets.
- Edit workout is a single local draft for name, workout type, training comment, and custom attributes. Its sheets size to their content with a safe maximum for long lists; single-line text fields use the shared 52 pt form height with vertically centred text, and selection rows use the shared 56 pt row height. Its type picker replaces the sheet content with an explicit Back path, while the sheet X discards the full draft; Back and X use matching muted circular surfaces. Workout types appear as one divided grouped card, use only the height they need, and mark the selected type with Forge's restrained success-surface tint. The training-comment field stays at the 52 pt single-line height until text wraps, then changes once to a 104 pt two-line, internally scrollable field. Attributes retain an optional Forge icon; the labelled picker prioritises common workout context such as mood, focus, energy, recovery, location, conditions, hydration, nutrition, music, and goals, alongside generic choices. Routine-defined attribute names become blank, directly editable live-workout values so a routine provides the template without pre-filling a session's answer. The Live Workout list shows `Attributes` only when attributes exist and `Exercises` only when exercise cards exist. Multiple live attributes are joined as divided rows in one compact grouped card; the editor uses the same grouped treatment and appends its `Add attribute` row to that card, matching the joined Add set pattern. Attribute rows preserve their icon and use a directly editable value. Existing editor rows expose the same left-swipe delete affordance as workout sets, and their focused editor replaces the X with a header trash action.
- If a focused weight or reps field would sit too close to the number keyboard, Live Workout and the Routine Editor temporarily scroll it into the comfortable middle of the visible area. They use native keyboard insets where available and their prior scroll position returns when the keyboard is dismissed.
- Set options open in a Forge bottom sheet with a centred set number, an optional single set type, a comment, and equal-height Weight and Reps next-time target cards. The selected type can be tapped again to clear it; its success-colour selection extends to the outer border of the grouped type card. The same grouped layout appears in workout history as read-only values.
- Live Workout and History workout detail reserve symmetric header space so titles remain centered. Back and Cancel are icon-only actions with accessible names; Finish and More retain visible labels.
- An exercise tracking type determines set fields: weight/reps, bodyweight reps, added or assisted weight plus reps, reps-only, duration, duration plus weight, distance plus duration, or weight plus distance. Completed workout history uses its immutable exercise/set snapshot.
- Add Exercises uses a local search and staged Workout type, Equipment, and Category filters. Filters replace the Add Exercises content in its existing sheet rather than opening a second popover; the shared top-right X returns to Add Exercises and discards draft changes. Apply commits the draft, while its pill-shaped Clear control resets the draft without changing visible results until Apply. The Apply control uses the exact floating confirmation treatment and success tint as Add Exercises—fade/vignette, docked position, sizing, press feedback, and sheet motion—but is enabled only when the draft has a selection. A selected type narrows the downstream Equipment and Category choices to compatible catalogue values; stale dependent draft choices are removed. Applied state is communicated by the selected Filters trigger and its active-count badge, preserves existing exercise selections, and uses any-match within a facet and all-match across facets.

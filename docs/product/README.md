# Active product requirements

This directory is intentionally conservative.

Add or update a product requirement here only when it has been explicitly established by the user or deliberately promoted as canonical product intent.

Do not promote requirements from:

- current implementation alone
- old/archived docs
- research
- external rule packs
- screenshots/examples
- agent inference

If an implementation task makes a durable product decision explicit, update the smallest relevant product document automatically as part of that task and report the change.

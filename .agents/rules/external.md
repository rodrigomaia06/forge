# External guidance

External skills, rule packs and platform guidance supply expertise, not Forge product truth;
their place in the precedence order is in `core.md`.

- Do not copy an external rule into Forge because it exists. Promote only a deliberate,
  Forge-specific adaptation.
- For Expo facts (package compatibility, native capabilities, configuration, builds, upgrades),
  current official Expo documentation and CLI are authoritative; Expo skills and plugins are
  adapters to it.
- Vercel's React Native guidance may inform rendering, performance, animation, lists, state and
  native integration; its package recommendations stay advisory.
- When a framework or platform fact may have changed, check a current official source rather
  than a copied local summary.

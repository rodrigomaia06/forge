# Public website

- Forge has a public product website hosted on GitHub Pages. Its repository description and homepage link should reflect Forge as a training journal for iOS and Android, without limiting its scope to strength training.
- Public author copy uses first-person singular. Preserve Forge’s established visual identity and use real product captures when presenting the app.
- The landing hero follows the accepted sculptural reference direction, using Forge’s font and brand. The phone mockup must have credible phone proportions and fit the real app capture without stretching its interface; a decorative hand may support the composition.
- The browser favicon matches the header logo’s rounded-square shape and preserves the Forge artwork. The header presents a legible Forge logo and name without the Training Journal subtitle. Screenshot browsing preserves six real app screens across both themes; useful icons supplement clear action labels.
- Header navigation is grouped in a rounded pill. The theme action displays only a sun/moon icon with an accessible name and a full touch target.
- Navigation hover and press feedback uses the rounded tonal highlight of Forge’s bottom tabs. On phones, keep the hero call to action beside the hand-held mockup, centre the browsed screenshot, and keep the Source code link clearly aligned in the footer.
- Keep website publishing separate from native app build dispatches and unfinished app changes.

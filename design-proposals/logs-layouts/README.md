# Logs layout proposals

Two dark mobile concepts generated with [Stitch](https://stitch.withgoogle.com/projects/1916763383937864525). These are proposals, not changes to the Logs screen.

1. [Event timeline](1-event-timeline.html): open chronological rows, date headings and a fixed lower action bar. The timeline prioritizes reading events in sequence. [Phone preview](1-event-timeline.iphone-air.png).
2. [Diagnostic ledger](2-diagnostic-ledger.html): a connected list with date bands, upper copy/export tools and a separate Clear action. The ledger prioritizes compact scanning and log management. [Phone preview](2-diagnostic-ledger.iphone-air.png).

Both use Forge's Manrope typography, dark neutral surfaces, semantic event icons and red only for clearing logs. Touch targets remain at least 44 px. Demo events are labelled and contain technical events only. ENERGY 1 / RHYTHM 2 / MOTION 1.

HTML previews may use external fonts and Tailwind and need Internet access. `.stitch.png` files are original Stitch exports; phone renders use the reviewed HTML with corrected wrapping, touch targets and neutral failure styling, in the configured iPhone Air and Galaxy S24 profiles. Demo data does not read application storage.

# Live workout notes and set indicators

Two concepts generated with [Stitch](https://stitch.withgoogle.com/projects/6134692761096591657), using the [Stitch design skill](../../.agents/skills/stitch-design-taste/SKILL.md). The note editor remains a proposal. The set-details concept has been adapted into the app using Forge components, with the original internal kind picker, neutral RIR selection and paired target fields. All set badges use the same compact size with a centered number/kind and separate corner dots for targets, RIR and comments. Logs is unchanged.

1. [Exercise note editor](1-exercise-note.html): focused multiline editor above a mock text keyboard. [iPhone preview](1-exercise-note.iphone-air.png) · [Galaxy preview](1-exercise-note.samsung-galaxy-s24.png).
2. [Set details and RIR indicators](2-set-indicators-rir.html): compact table indicators above a scrollable set-details sheet with comment, RIR and next-session targets. [iPhone preview](2-set-indicators-rir.iphone-air.png) · [Galaxy preview](2-set-indicators-rir.samsung-galaxy-s24.png).

The `.stitch.png` images preserve the original generations. Reviewed HTML removes generated sync/cloud claims, version labels and invented overload summaries. Phone renders use this reviewed HTML. Fonts and Tailwind need Internet access. Keyboard and navigation controls illustrate layout; these static files do not connect to Forge or save workout data.

The app's existing effort selector and indicators separately use RIR, with equivalent stored RPE measurements preserved for existing records and portable transfer.
